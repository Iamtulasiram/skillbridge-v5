SKILLBRIDGE V5

1. Extract this folder.
2. Double-click START_SKILLBRIDGE.bat.
3. Open http://127.0.0.1:3000 if it does not open automatically.

Flow:
Create Account -> Foundation Skill Assessment -> Career Recommendations -> Select Career Path -> Career-Specific Assignments -> Results % -> Career-Matched Internship Opportunities -> Dashboard

Skill levels:
Beginner, Intermediate, Advanced. Percentages are NOT entered during assignments. Final readiness is calculated from selected levels: Beginner=35, Intermediate=65, Advanced=90, averaged across completed career assignments.

The opportunity catalogue is sample prototype data. Verify live openings on the linked official career pages.

Backend data is stored in data.json. This is a college/demo prototype, not production authentication infrastructure.
